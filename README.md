#  Spotlight: tinyinfer

<p align="center">
  <a href="https://github.com/Aadithya-kl/tinyinfer">
    <img src="https://raw.githubusercontent.com/Aadithya-kl/tinyinfer/main/docs/demo.svg" alt="tinyinfer decoding at 235 tok/s on an RTX 3050 laptop GPU" width="820">
  </a>
</p>

**[tinyinfer](https://github.com/Aadithya-kl/tinyinfer)** is an LLM inference engine I wrote **from scratch in C++/CUDA**: no PyTorch, no cuBLAS, every GPU kernel by hand.

-  **235 tokens/sec** on a 6 GB RTX 3050 laptop GPU, **77%** of the hardware's memory-bandwidth limit
-  Autotuned FP16 / INT8 / INT4 GEMV kernels, GQA split-K flash-decoding (3.6x faster at long context), fused QKV & gate/up, CUDA graphs
-  Output matches the HuggingFace reference within **0.1%**

**Contributions welcome!** Check the [good first issues](https://github.com/Aadithya-kl/tinyinfer/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22). A ⭐ helps a lot.
